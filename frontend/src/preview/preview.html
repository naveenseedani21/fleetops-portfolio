ENGINEERING / FLEETOPS

Built around explicit boundaries.

Angular · Java 21 / Spring Boot · Keycloak · DynamoDB Local · Docker

Identity and tenant isolation

The real API verifies JWT issuer, audience, organization membership and role. Administrators provision; scoped machines report; viewers read.

Durable report integrity

Accepted report IDs, device state, evidence and audit writes are atomic. Replays do not duplicate effects; conflicting IDs and stale reports are rejected.

Independent lifecycle and compliance

A failed policy does not retire a device. A passing policy does not reactivate one. Unknown settings remain unknown.

Reproducible delivery

Docker and real authenticated browser tests accompany backend, frontend and simulator checks. Terraform is an unapplied AWS foundation; no backend is hosted here.
